AI-ready read views

Trust chain

Landing evidence is the source of truth. Before marts publish, canonical data is independently rebuilt from authenticated landing evidence and compared byte-for-byte. A self-consistent forged manifest is therefore insufficient.

Current tool stack

  • Python 3.11 standard library
  • SQLite for evidence registry
  • JSON / JSONL / CSV artifacts
  • SHA-256 manifests
  • unittest black-box tests
  • Git for version control

Deliberately not used yet

  • Databricks / Spark
  • Cloud warehouse
  • dbt / Airflow
  • Kafka / streaming
  • BI dashboard

Reason: first prove semantics and trust. Add scale tools only when volume or operations require them.
